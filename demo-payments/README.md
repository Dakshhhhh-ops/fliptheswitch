# demo-payments

A small payments service: a card vault, partner settlement sessions, signed
merchant webhooks, receipts and customer records.

It is the target codebase for Crypto Migration Desk. Its crypto is typical
of a service written before post-quantum algorithms were available, and it
is migrated in the demo.

```sh
npm test   # Node 24.7 or later, no dependencies
```

All data in the tests is made up.
